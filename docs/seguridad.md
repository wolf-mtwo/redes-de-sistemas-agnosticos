# Seguridad

A medida que las redes conectaron sistemas cada vez más críticos (bancos, hospitales, gobiernos), proteger esas comunicaciones dejó de ser opcional. La seguridad en redes cubre desde verificar quién eres (autenticación) hasta cifrar el canal por el que viajan tus datos (TLS) y defenderse de quienes intentan interceptarlos o interrumpirlos.
