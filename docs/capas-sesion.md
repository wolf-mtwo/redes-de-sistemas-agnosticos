# Capa de sesión

Establecer, mantener y cerrar una sesión de comunicación entre dos sistemas.

**Ejemplos:**
1. C#: reutilizar un `HttpClient` con cookies entre varias peticiones de una misma sesión.
2. Java: `HttpSession` en una aplicación web para mantener el estado del usuario.
3. Comando: `curl -c cookies.txt -b cookies.txt` — mantener sesión entre peticiones.
