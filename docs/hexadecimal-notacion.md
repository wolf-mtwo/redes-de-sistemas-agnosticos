# Notación hexadecimal

Representación compacta de binario, muy usada para direcciones de memoria, colores y bytes.

**Ejemplos:**

1. C#
```csharp
Convert.ToString(42, 16); // "2a"
```

2. JavaScript
```javascript
(42).toString(16); // "2a"
```

3. Comando — ver el contenido de un archivo en hexadecimal
```bash
xxd archivo.bin
```
