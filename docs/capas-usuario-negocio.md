# Capa de usuario / negocio

Capa informal que interpreta la respuesta técnica en términos de reglas de negocio.

**Ejemplos:**
1. Regla de negocio: si la API responde código 402, mostrar pantalla de pago.
2. Webhook que dispara lógica de negocio al recibir un evento (ej. una orden pagada).
3. Regla de UX: mostrar distintas opciones de menú según el rol del usuario autenticado.
