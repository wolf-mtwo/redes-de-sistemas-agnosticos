# Buffers

Cuando la velocidad de quien produce datos (disco, red, sensor) no coincide con la de quien los consume, se necesita un espacio intermedio en memoria para acumularlos: eso es un buffer. Es una pieza clave desde los primeros sistemas de E/S por lotes hasta el streaming de datos en tiempo real de hoy.
