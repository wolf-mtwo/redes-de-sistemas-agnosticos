# Deserialización de valores primitivos

Proceso inverso a la [serialización de valores primitivos](serializacion-valores-primitivos.md): tomar la representación en string y reconstruir el valor original con su tipo.

Ejemplos:
- Un `string` a `int` (`"42"` → `42`)
- Un `string` a `Date` (`"2026-08-31T00:00:00Z"` → objeto `Date`)
