# Representación binaria de datos

Cómo un número, carácter o valor se almacena como secuencia de bits.

**Ejemplos:**

1. C#
```csharp
Convert.ToString(42, 2); // "101010"
```

2. JavaScript
```javascript
(42).toString(2); // "101010"
```

3. Comando — convertir 42 a binario en la terminal
```bash
echo "obase=2; 42" | bc
```
