# Protocolos de comunicación

Cuando dos computadoras necesitan hablar, necesitan reglas compartidas: quién habla primero, cómo se marca el fin de un mensaje, qué hacer si algo se pierde. Los protocolos de comunicación son ese acuerdo, y existen desde los primeros módems telefónicos hasta los sistemas de eventos distribuidos actuales.
