# Serialización

Antes de que existiera un formato estándar como JSON, cada sistema guardaba y transmitía datos a su manera, lo que hacía casi imposible que dos programas distintos se entendieran. La serialización nació para resolver eso: un acuerdo de formato que cualquier sistema puede leer y escribir.
