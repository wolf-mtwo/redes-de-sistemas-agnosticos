# Binario y hexadecimal

Todo dato en una computadora se almacena finalmente como binario (bits: 0 y 1), herencia de que los primeros circuitos digitales solo podían representar dos estados eléctricos (encendido/apagado). El hexadecimal (base 16) surgió como una forma corta de escribir binario para humanos: 4 bits = 1 dígito hex, así que un byte se escribe con solo 2 caracteres.
