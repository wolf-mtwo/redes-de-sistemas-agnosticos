# Operaciones a nivel de bits

Manipular datos directamente en su representación binaria (AND, OR, XOR, shifts).

**Ejemplos:**

1. Java — AND a nivel de bits
```java
int resultado = 5 & 3; // 101 & 011 = 001
```

2. C# — shift a la izquierda
```csharp
int desplazado = 1 << 4; // 16
```

3. JavaScript — XOR a nivel de bits
```javascript
5 ^ 3; // 6
```
