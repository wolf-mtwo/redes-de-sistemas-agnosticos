# Capas del modelo de comunicación

Antes de 1984 cada fabricante tenía su propio stack de red incompatible con los demás (SNA de IBM, DECnet, etc.). Ese año la ISO publicó el modelo OSI para que cualquier sistema, sin importar el fabricante o lenguaje, pudiera comunicarse dividiendo el proceso en capas independientes. En la práctica se suele agregar una capa 8 informal (usuario/negocio) sobre las 7 oficiales.
