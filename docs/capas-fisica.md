# Capa física

Transmisión de bits crudos como señales eléctricas, luz u ondas de radio.

**Ejemplos:**
1. Comando `ethtool eth0` — ver velocidad y estado del enlace físico.
2. Comando `ip link show` — ver si la interfaz física está activa (UP/DOWN).
3. Herramienta: multímetro/osciloscopio para medir la señal eléctrica en un cable de red.
