# Transporte de datos en tiempo real

TCP y UDP existen desde los años 70 como las dos formas base de mover datos por una red: uno prioriza la confiabilidad, el otro la velocidad. Sobre esa base nacieron protocolos más recientes como MQTT (creado en 1999 para monitorear oleoductos con enlaces satelitales muy limitados), pensados para sensores, IoT y eventos en tiempo real.
